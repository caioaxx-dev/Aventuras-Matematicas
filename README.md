# Aventuras Matemáticas

Jogo educativo acadêmico do projeto Cruzeiro HUB.

## Tecnologias
HTML5, CSS3 e JavaScript ES6+. O protótipo utiliza LocalStorage para guardar o progresso no navegador.

## Executar
Abra `index.html` em um navegador. Não há dependências para instalar.

## Estrutura
- `index.html` — telas e interface
- `style.css` — visual, animações, responsividade e acessibilidade
- `script.js` — lógica, fases, pontuação e progresso
- `assets/` — espaço para imagens e sons
- arquivos `.md` — planejamento e documentação

## GitHub
Suba os arquivos do projeto, não o arquivo ZIP.

## Vercel
Conecte o repositório GitHub à Vercel e publique como site estático.

## Teste no celular
No Chrome/Opera: `F12` → modo dispositivo ou `Ctrl+Shift+M`.
