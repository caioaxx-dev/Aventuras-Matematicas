# Relatório do Projeto

## Objetivo
Criar um jogo educativo de matemática com desafios curtos e progressivos.

## Solução
Cinco áreas: operações, multiplicação/divisão, geometria, tempo e revisão final. O jogador recebe feedback, pontos e mantém o progresso no navegador.

## Tecnologias
HTML5, CSS3 e JavaScript ES6+.
